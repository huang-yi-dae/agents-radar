## 3. Trend Signal Analysis

Three clear signals emerge from today's data. First, **Agent Skills are the new gold rush**. The word "skills" appears across stacks: JS-based agent-skills, shell-based skills for engineers, a scientific agent skills library (32k stars), a python-based superpowers framework — even a caveman-themed token-saving skill (96k stars). These are lightweight, copy-into-.agents-directory assets, representing a decisive shift away from heavy agent frameworks toward composable, prompt-and-script packs that work across Claude Code, Codex, OpenCode, Cursor, and more. This is the ecosystem converging on a portable "agent app" format.

Second, **persistent, team-level agent memory is becoming infrastructure**. TencentDB-Agent-Memory (a team memory hub with governance), mem0 (universal memory layer), claude-mem, cognee, and loopx (durable goals, evidence logs, verifiable handoffs) all tackle the same problem: agents forget. The trend is moving beyond context windows toward structured memory banks — chat memory, skills, knowledge graphs, code graphs — shared across teams and frameworks. Tencent's entry as a cloud-vendor-backed solution is notable.

Third, **code intelligence is being re-architected around local-first graphs**. code-review-graph and Graphify both avoid vector stores entirely, using deterministic AST parsing to build persistent code maps. This challenges the RAG-everything orthodoxy, offering benchmarked context reductions via structure rather than embeddings. Combined with Cloudflare's computer (giving agents a desktop) and DeepSeek-Reasonix (prefix-cache-stable long-running agents), the frontier is clearly pushing toward agents as long-lived, well-instrumented workers with institutional memory.
